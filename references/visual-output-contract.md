# 圖像交付規格

## 十個必備模組

| 模組 | 預設交付 | 判定重點 |
|---|---|---|
| 主視覺圖 | 1張半身或胸像 | 臉部清楚；沿用來源畫風與角色，不額外美化改造五官 |
| 全身視圖 | 正面、45度、90度側面、背面，共4張獨立圖 | 標準三視圖以外，45度為固定必備；四張完整顯示頭頂、髮尾、披風與鞋底 |
| 身體比例圖 | 正面站姿＋頭身分段與肩、腰、胯、膝、腳底參考線 | 量出外觀比例，不新增身高、年齡或身體尺寸設定；有帽子時區分頭頂與帽頂 |
| 表情差分 | 8張同角度頭像＋1張總覽 | 基本、微笑、大笑、驚訝、生氣、難過、害羞、認真；使用者可替換清單 |
| 眼睛細節 | 單眼放大，必要時雙眼對照 | 保留眼型、虹膜層次、瞳孔、高光、睫毛與眉眼關係；左右不同時兩眼皆畫 |
| 髮型結構 | 正面、側面、背面頭部細節，必要時分層示意 | 明確顯示瀏海、鬢髮、後髮、分線與長短層次；被帽子遮住的部分標示推定 |
| 服裝細節 | 足以說明來源特徵的局部放大圖 | 展示衣領、袖口、腰部、接縫、衣襬、披風與鞋靴等關鍵處，不附長篇衣物清單 |
| 飾品小物 | 各主要飾品／持有物的局部圖或獨立圖 | 外形、附著處、方向、左右位置可辨識；原圖可見部分優先，未見反面不憑空增加紋樣 |
| 標準色票 | 覆蓋角色主要可見色域的色塊圖，通常8～12色 | 每塊只需部位短名與HEX；避開背景、強高光、陰影與邊緣混色；標記為來源估計色 |
| 簡化線稿 | 正面、45度、90度側面、背面共4張 | 對應已驗收全彩圖的結構與比例，不用自動邊緣偵測取代可讀線稿 |

表情差分使用同一角度、臉部尺度與裁切，預設以45度基準為主。允許情緒造成眼眉嘴與輕微臉頰變化；不因表情改變髮際、下顎、鼻子位置、頭部方向與配件。這些是靜態參考圖，不要求達到遊戲疊片的像素鎖定。

## 視角與站姿

- `front`：正面，頭與軀幹正對相機。
- `three_quarter`：相機自正前方繞至角色自身左側約45度，能看見正面與左側；若改看右側，將 `camera_side` 記為 `character_right`。
- `profile`：相機位於角色自身左側約90度，與45度採同一側；改側亦須記錄。
- `back`：180度背面。

視圖以中性站姿、基本表情、自然垂手與穩定重心呈現。手臂可稍離軀幹以讀清衣服，但不加入表演動作；視線跟隨頭部，不為看鏡頭另扭頭。使用平視、弱透視，維持一致體型與參考尺度，避免廣角縮短雙腿或放大頭部。

正面與45度獨立圖為主要交付物。全身各圖使用一致畫布與人物尺度，留足四周安全邊界。不要以各圖外框寬度各自縮放，造成披風較寬的視角人物反而變小。對照時按頭部尺度與腳底基準檢查，帽飾與輪廓造成的局部差異不拉伸硬對齊。

## 解析度與版面建議

以下為預設製作目標，可依工具實際能力調整並記錄實際尺寸，不以放大後像素數宣稱新增細節。

- 全身原圖：人物可見高度以約2000 px以上為目標，正面與45度優先取得高細節版本。
- 表情：單張頭像以768～1024 px方形畫布為目標；其他細節以能辨讀關鍵特徵為準。
- 純圖素材用透明底或乾淨純色底，避免背景投影干擾輪廓；設定集用白色或低彩度底。
- 預設拆成3張設定頁：01全身視角與比例、02主視覺與臉部髮型、03服裝配件與色票。簡化線稿可置於01頁；排不下時增加第04頁，不縮到無法閱讀。
- 01頁的正面、45度、側面、背面應是主要內容；主視覺與裝飾不擠壓它們的版面。
- 整套設定集只列姓名、讀音、3～5個設計重點及圖像必要標籤，不放背景故事、性格、角色定位或額外規格表。

## 3～5個設計重點

每項寫成「辨識特徵＋不可丟失的視覺細節」，以能指導重畫為準，例如「左右配件固定在角色自身哪一側」，不要只寫可愛、優雅、清新等抽象詞。

以下僅是本次 `Phebe_gun_set.png` 的觀察示例，不能變成所有人物的預設設定：

1. 粉色長髮與青藍色雙眼：保留額前瀏海分束、長髮輪廓及原有眉眼比例。
2. 白色貝雷帽與長披風：保留帽型、肩部覆蓋、披風前開口與長度。
3. 酒紅色縱向線條短連身服：保留高領、腰身與原圖衣襬相對位置。
4. 青綠色金框胸針與斜腰帶：胸針固定胸前，槍套位於角色自身左側，彈藥位於自身右側；以原圖可見位置核對，禁止整人鏡像。
5. 白色過膝繫帶長靴：保留前方交叉繫帶、靴口裝飾、鞋頭與鞋跟形狀。

來源未顯示帽子背面、披風後方接合與槍套背面，不能將生成補完描述為原作既定結構。來源沒有正式姓名讀音或公分身高；`Phebe` 檔名片段只能作工作代號，等待使用者提供正式文字。

## 通過條件

1. 正面、45度、90度、背面四張齊全，且正面與45度不是縮圖或放大截圖。
2. 可見五官、頭身、髮長、服裝輪廓、鞋型及左右配件保持一致。
3. 45度能清楚讀出面部與軀幹的立體轉向，並且頭腳完整。
4. 全身與細節圖相互一致，8種表情沒有換臉或改變基準頭部角度。
5. 色票可對應來源部位；推定結構有記錄；3～5個設計重點具體可執行。
6. 姓名與讀音未知可留空；必要圖像缺失、重大外觀衝突或尚未目視檢查時，整套狀態必須為 `partial`，不能標為完成。
