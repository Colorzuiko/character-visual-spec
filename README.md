# 角色視覺規格表

`character-visual-spec` 是從人物全身立繪建立角色視覺規格表的 Codex 技能。先確立正面與45度全身基準，再整理側面、背面、八種表情、外觀細節與簡化線稿，供後續立繪製作維持角色一致性。

## 取得與使用

[下載最新版 ZIP](https://github.com/Colorzuiko/character-visual-spec/archive/refs/heads/main.zip)，解壓後將完整資料夾命名為 `character-visual-spec`。保留 `SKILL.md` 與 `references/` 的相對位置。

讓 Codex 讀取 [SKILL.md](SKILL.md)，並提供一張人物全身立繪及工作輸出位置。姓名、讀音與外觀修改可以另外提供；未提供的身分資訊會留空，來源檔名只作工作代號。

可使用以下請求：

> 使用 $character-visual-spec，依這張全身立繪建立角色視覺規格表。先完成正面與45度基準，再製作側面、背面、八種表情與外觀細節，保留獨立圖並組成設定集，輸出到新的版本資料夾。

只需要規劃時，請明確指定「先規劃，不生成圖片」。

## 輸出內容

| 模組 | 內容 |
| --- | --- |
| 主視覺 | 臉部清楚的半身或胸像 |
| 全身視圖 | 正面、45度、90度側面、背面四張獨立圖 |
| 身體比例 | 頭身分段與肩、腰、胯、膝、腳底參考線；標示視覺估計 |
| 表情 | 基本、微笑、大笑、驚訝、生氣、難過、害羞、認真八張頭像及總覽 |
| 眼睛與髮型 | 眼型、虹膜與髮型結構細節 |
| 服裝與小物 | 衣物和主要配件的局部放大圖 |
| 標準色票 | 主要可見色域、部位短名與 HEX；標示來源估計色 |
| 簡化線稿 | 對應四個全身視角的結構參考 |
| 閱讀用設定集 | 依資訊量分頁排版，保留獨立原圖 |
| 製作與交接資料 | 素材索引、三至五項設計重點、推定項目與檢查結果 |

完整尺寸目標、視角與通過條件見 [圖像交付規格](references/visual-output-contract.md)。

## 工作流程

1. 檢視來源並鎖定外觀，分別記錄原圖可見、依原圖推定與使用者指定的資訊。
2. 先建立正面與45度基準，確認五官、頭身、服裝及左右配件一致。
3. 引用已檢查的基準擴充其他視角、表情與細節；修正不合格模組。
4. 保留獨立素材後再排版，檢查跨視角一致性、可讀性與實際解析度。
5. 交付索引及設計重點，讓後續立繪選用獨立正面或45度圖。

來源未顯示的結構會記錄為推定；沒有身高資料時不新增公分數。各次輸出使用新版本目錄，保留來源與既有成品。

## 執行條件與交接

此儲存庫提供技能指示與參考文件。製作圖片需要執行環境具備可引用參考圖的圖片生成／編輯工具；裁切、取色、對齊與排版依實際環境處理。

八種表情是靜態外觀參考。後續製作遊戲立繪與動畫時，仍須建立目標畫布的母圖，重新驗收並量測眼嘴座標。素材索引與下游交接格式見 [輸出與下游交接](references/standing-portrait-handoff.md)。
